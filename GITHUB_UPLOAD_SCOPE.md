# GitHub Upload Scope

This workspace contains code, strategy documents, local automation state, generated media, cookies, and nested repositories.

Safe upload scope:

- Platform intelligence automation source and templates.
- Basketball quick-cut source code.
- Sports psychology source code, strategy docs, and templates.
- Public strategy documents and SOPs.
- Example configuration files.

Excluded from upload:

- Cookies, credentials, local config, and notification secrets.
- `node_modules`, `.venv`, caches, logs, generated databases.
- Generated video/audio/image assets and daily output packages.
- Large raw media and frame extraction folders.

Before pushing to GitHub, confirm the target repository URL and whether nested projects should be uploaded as normal folders or kept as separate repositories.
